# Commentary
- For this task, I decided to generate a dynamic piece of music using FMOD, as I wanted to learn a different audio creation tool compared to Logic Pro. To get everything started, I installed FMOD, which was quite simple. The problem was that when I opened it, the interface was completely empty—something entirely different from Logic. I was recommended a couple of tutorials (https://www.youtube.com/watch?v=A51Zl9w_-Nc&list=PLp4vT3ssm5SUgEJpDeA0Nb-1BKGxnDu2mto) to help me become familiar with FMOD since it was new territory for me.
- I took it step by step, following the tutorials thoroughly, and quickly realised that I had to create the audio files I wanted to use in FMOD. I was excited about this because it allowed me to combine two areas—one I was already acquainted with and one I am currently learning.
- I found a sample that I liked and added slow Soul/R&B drums that progress into a more aggressive, rap-influenced style. I was happy with the result, so I exported the individual stems in a lossless format to avoid losing any effects due to compression.
- After importing the stems into FMOD, I created different audio regions and moved each instrument into its allocated section. I divided the track into two regions using markers and added looping markers so the regions loop automatically when they reach the end.
- To achieve transitions between the two regions, I added a Transition Region, which allows the transition to happen at any point during the looping section. If I had added a “Transition” or “Transition To” marker, the song would only transition once it had passed that marker—something I did not want. I covered both regions with separate transition areas so the track can move back and forth between them.
- I added a condition for the track to proceed to the next region by creating and enabling Music_Transition. Every time the condition is “on,” the track moves to the second section, and when it is “off,” it returns to the first. Since the transition was too abrupt, I quantized it so it waits for a moment before continuing (as shown in the video).
- Since I had some time left, I decided to make the process even smoother. Between the two regions, I added fade-in and fade-out effects so the volume gradually decreases and then increases during transitions, preventing overlapping sounds that may cause discomfort.
- What I consider procedural about my project is that the user can move back and forth between the two regions whenever the condition is met. It is up to the user to decide how the track progresses. It can be played as a normal song or interacted with to make it more dynamic.
